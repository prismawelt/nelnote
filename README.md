# NEL NOTE

네이티브 iOS 앱과 도장깨기 위젯은 [iOS 안내](ios/README.md)를 참고하세요. 최신 IPA는 [Releases](https://github.com/prismawelt/nelnote/releases/latest)에서 받을 수 있습니다.

## 웹 앱

게임, 애니, 미연시, 책 진행 기록 앱의 아이폰용 버전이에요.
웹 주소로 올려 두고, 사파리에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 올리는 방법 (한 번만)

1. 브라우저에서 app.netlify.com/drop 열기
2. 이 폴더(또는 압축 파일)를 끌어다 놓기. `index.html`이 맨 위에 있어야 해요
3. 나온 주소(예: https://이름.netlify.app)를 친구에게 보내기
4. 가입하지 않고 올리면 24시간 뒤에 사라져요. 계속 쓰려면 가입해서 사이트를 내 것으로 등록하세요.

## 아이폰에 설치하기 (친구가 할 일)

1. 받은 주소를 **사파리**로 열기
2. 공유 버튼(네모에 위쪽 화살표) 누르기. 버튼이 안 보이면 오른쪽 아래 `⋯` 안에 있어요
3. **홈 화면에 추가** → 추가
4. 이제 홈 화면의 NEL NOTE 아이콘으로 열어서 쓰기

## 알아 두기

- 기록은 각자 휴대폰 안에만 저장돼요. 주소를 아는 사람도 남의 기록은 볼 수 없어요.
- 홈 화면에서 아이콘을 지우면 기록도 함께 지워져요. 오른쪽 위 톱니바퀴 → 백업 보내기로 가끔 백업해 두세요.
- 사파리 탭에서 쓴 기록과 홈 화면 아이콘으로 쓴 기록은 따로 저장돼요. 홈 화면 아이콘으로만 쓰세요.
- 한 번 연 뒤에는 인터넷이 없어도 열려요.
- 사파리 웹 앱에는 위젯이 없어요. 네이티브 iOS 앱에는 도장깨기 위젯이 포함되어 있어요.
- 나중에 화면을 고쳐서 다시 올리면, 친구 폰에는 앱을 두 번 열었을 때 새 버전이 적용돼요.
